## Overview

OpenJKDF2 is an open-source, fully functional reimplementation of the Jedi Knight: Dark Forces II game engine, enabling the 1997 classic to run natively on modern Windows, Linux, and macOS with widescreen rendering, unlocked framerate, improved multiplayer infrastructure, and a foundation for community mods and extensions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OpenJKDF2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Native Port** | Runs Jedi Knight natively without DOSBox or compatibility layers |
| **Widescreen** | Widescreen and ultrawide aspect ratio support for modern displays |
| **Unlocked FPS** | Smooth high-framerate gameplay with interpolated physics |
| **Multiplayer** | Updated multiplayer network code for modern internet connections |
